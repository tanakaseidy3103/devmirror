# Mac Bridge セキュリティ設計

## 接続（MVP1）

| 脅威 | 対策 |
|---|---|
| なりすまし Mac（MITM） | 登録時、ユーザーが Mac 本体で確認した SHA256 指紋と `ssh-keyscan` の結果を照合し、不一致なら登録拒否。以降は `StrictHostKeyChecking=yes` + DevMirror 専用 known_hosts（DB を正として毎回書き出し）。ホスト鍵が変わった場合は `host_key_mismatch` として中止。自動信頼（TOFU）や検証の無効化は一切しない |
| 公開ホストへの接続 | IP 直接指定も DNS 名も、**解決した全アドレス** がグローバル IP でないことを接続のたびに確認する。ssh には検査済みの IP を渡し、ホスト鍵は `HostKeyAlias=<登録ホスト名>` で照合する（検査後に DNS が書き換えられても公開ホストへは接続しない）。許可するには `MAC_BRIDGE_ALLOW_PUBLIC_HOSTS=true`（非推奨） |
| 認証情報の漏えい | パスワードは扱わない（`BatchMode=yes`, `PasswordAuthentication=no`）。秘密鍵は保存せずパスのみ保存。API レスポンスに鍵パス・known_hosts 行を含めない |
| ローカルのコマンドインジェクション | シェルを使わず argv で起動。ホスト名・ユーザー名は正規表現で検証（先頭 `-` 不可）、`--` で宛先とオプションを分離。`-F none` でユーザーの ssh_config（ProxyCommand 等）を無視 |
| 他の端末からの操作 | API に認証が無いため、Mac Bridge の全エンドポイントは loopback（127.0.0.1 / ::1）以外からの要求を 403 で拒否する。バックエンドを `0.0.0.0` で起動しても他の PC から Mac は操作できない。起動は `uvicorn app.main:app --host 127.0.0.1` を推奨 |
| ハング・資源枯渇 | 接続 / 全体タイムアウト。超過時はプロセスを kill。出力は上限で切り詰め |

## ビルド（MVP2）

| 脅威 | 対策 |
|---|---|
| 任意コマンド実行 | Mac で実行するコマンドは `mac_build.py` 内の固定テンプレートのみ（ARCHITECTURE.md 5 章）。フロントエンドから受け取るのは「候補から選んだ値」だけで、scheme / configuration は Mac から取得した候補、宛先は接続テストで取得したシミュレータ UDID と照合する。値はすべて `shlex.quote` する。LLM にシェルは渡さない |
| パストラバーサル（Windows 側） | 選択できるフォルダは `MAC_BRIDGE_PROJECT_ROOTS`（既定: ホーム配下）に限定。シンボリックリンク / ジャンクションも解決してから判定。プロジェクトは検出結果と完全一致したものだけ |
| パストラバーサル（Mac 側） | 作業フォルダ名はサーバ生成の uuid4 hex のみ（正規表現で検証）。展開先は `~/DevMirrorWorkspaces/<id>/src` 固定。アーカイブにはシンボリックリンク・絶対パス・`..` を含めない（macOS の bsdtar も既定で拒否） |
| 秘密情報の転送 | `.git`・`DerivedData`・`build`・`xcuserdata`・`node_modules` は送らない。コード署名は無効（`CODE_SIGNING_ALLOWED=NO`）で、証明書・プロビジョニングプロファイルは扱わない |
| 他プロジェクトへの影響 | ビルドごとに別フォルダ。`-derivedDataPath` も作業フォルダ内。削除は自分のフォルダだけ |
| 資源枯渇 | 転送サイズ上限（既定 500 MB）、転送 / ビルドのタイムアウト（既定 600 / 1800 秒）、ログ上限（既定 20 MB）、Mac ごとに同時実行 1 件 |
| 残留プロセス | キャンセル・タイムアウト時はローカルの ssh を kill し、さらに Mac 側の xcodebuild に SIGTERM を送る |

## 既知の制限

- ビルド時はユーザー本人の macOS アカウントで実行される。より強い隔離が必要なら、ビルド専用の macOS ユーザーを作成してそのユーザーで登録する（推奨）。
- `.local`（mDNS）名の解決結果は OS に依存する。解決できない場合は IP アドレスで登録する。
- `.gitignore` は解釈しない（除外は固定リスト）。秘密情報をプロジェクトフォルダ内に置かないこと。
